Règles de formation.

Formation générale

Infinitif + terminaisons :

-ai -as -a -ons -ez -ont

⚠ « -ai » se prononce [é]

Verbes en -RE

On supprime le « e » final avant les terminaisons.

  • mettre → mettr- → il mettra
  • lire → lir- → nous lirons
  • prendre → prendr- → tu prendras
  • suivre → suivr- → je suivrai
Verbes en -ayer

Deux formes acceptées :

payer → payerai ou paierai

Ce site utilise la forme en -ai-.

Verbes en -yer (sauf -ayer)

Le « y » devient « i » (sauf envoyer).

  • appuyer → appuier- → j'appuierai
  • essuyer → essuier- → tu essuieras
Double consonne — -eler / -eter
  • appeler → appell- → j'appellerai
  • rappeler → rappell- → je rappellerai
  • jeter → jett- → je jetterai
Accent grave — -e_er

La 1ʳᵉ pers. du présent s'applique à toutes les personnes du futur.

  • acheter → achèter- → j'achèterai
  • lever → lèver- → je lèverai
  • espérer → espèrer- → j'espèrerai
  • répéter → répèter- → je répèterai

Verbes irréguliers.
